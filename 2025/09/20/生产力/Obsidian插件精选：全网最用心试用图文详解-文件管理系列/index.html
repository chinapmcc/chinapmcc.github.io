Obsidian插件精选：全网最用心试用图文详解-文件管理系列

今天来给大家安利一波Obsidian的文件管理插件！如果你也在为笔记文件杂乱无章、附件存放杂乱、文件清理麻烦这些问题烦恼，那可太有福了。我亲自试用了一圈，把超好用的文件管理插件都整理出来啦，快来看看有没有你需要的那一款，直接冲就完事儿！😎

1. Custom Attachment Location

版本：9.2.2
Github仓库地址：https://github.com/RainCat1998/obsidian-custom-attachment-location
简介：自定义附件位置， 用类似参数${noteFileName}, ${date:format}。
下载插件：obsidian-custom-attachment-location-9.2.2.zip，解压至plugins下.\.obsidian\plugins\

功能点：

  • 自定义存储路径：用自定义变量指定附件的保存位置，非默认笔记目录。
  • 自动重命名：根据规则自动重命名文件夹，附件文件。
  • 自动移动附件：拖入编辑器时自动移动到指定路径。
  • 冲突检测：避免同名文件覆盖。
  • 批量处理：一键整理附件，移动并重命名。
  • 删除孤立附件：当笔记被删除时，其孤立附件也会被删除。
  • 排除特定路径：设置排除路径，避免处理。

使用方法：

新附件的位置

相对路径开头放置./

  • 参数例子：
    • 当前笔记文件名=./assets/${noteFileName}
    • 当前笔记的文件夹名称=./assets/${noteFolderName}
生成的附件文件名
  • 参数例子：
    • 年月日时分秒毫秒=file-${date:YYYYMMDDHHmmssSSS}
    • 附件生成的文件名={generatedAttachmentFileName}
    • 随机值={random}
  • 更多参数用法

2. File Cleaner redux

版本：1.11.1
Github仓库地址：https://github.com/husjon/obsidian-file-cleaner-redux
插件简介：File Cleaner Redux 是一个 Obsidian 插件，旨在帮助用户清理保险库中的空文件和未使用的附件。它可以根据用户定义的规则，删除大小为0字节的Markdown文件和指定类型的附件文件，还可以递归删除空文件夹。
插件下载：obsidian-file-cleaner-redux-1.11.1.zip，解压至plugins下.\.obsidian\plugins\

功能点：

  • 删除大小为0字节的Markdown文件。
  • 删除/包含用户定义的附件文件（例如：jpg、png、gif、svg、pdf等）。
  • 支持清理仅包含特定frontmatter的空文件。
  • 递归删除空文件夹。
  • 文件夹排除/包含。
  • 设置删除位置，包括移动到系统垃圾箱、移动到Obsidian垃圾箱或永久删除。

使用方法：

单击“文件清理器”功能区图标或为“清理文件”命令添加一个快捷键。

3. Auto File Organizer

版本：1.0.8
Github仓库地址：https://github.com/mofukuru/auto_file_organizer
插件简介：Auto File Organizer 能够根据文件扩展名自动将文件分类到指定文件夹中。该插件特别适合希望简化文件管理的用户。
插件下载：obsidian-auto-file-organizer-1.0.8.zip，解压至plugins下.\.obsidian\plugins\

功能点：

  • 新添加到 Obsidian 仓库中的文件将根据其扩展名或 Tag 自动移动到指定的文件夹中。
  • 用户可以在插件设置中设定分配规则，编辑现有规则。
  • 用户可通过“重新组织Vault”功能对整个Vault进行整理。

使用方法：

  1. 设置文件夹移动规则。
  2. 编辑现有规则，可以在设置中的列表编辑或删除现有的映射。
  3. 优先级设置和禁用，用户可以在设置中调整映射的优先级和启用/禁用设置

4. Pandoc

版本：0.4.1
Github仓库地址：https://github.com/OliverBalfour/obsidian-pandoc
最新安装包： https://github.com/jgm/pandoc/releases/latest
插件简介：Pandoc 是一个通用的文档转换工具，它能够将文档从一种格式转换为另一种格式。对于 Obsidian 用户来说，Pandoc 插件可以极大地增强 Obsidian 的文档处理能力，允许用户将笔记转换成多种格式，如 Html、DOCX、EPUB 等，非常适合需要将笔记导出为不同格式文档的用户。
插件下载：obsidian-pandoc-0.4.1.zip，解压至plugins下.\.obsidian\plugins\

功能点：

  • 文档转换：支持将 Markdown 文件转换为多种格式，包括 Html、DOCX、EPUB 等。
  • 引用和书目管理：支持添加引用和书目，方便学术写作和研究。
  • 图表和图像处理：在转换过程中正确处理图表和图像，确保文档的完整性和美观性。
  • 多语言支持：支持多种语言的文档转换，满足不同语言用户的需求。

使用方法：

  • 使用命令面板（Ctrl+P 或 Cmd+P），输入 Pandoc: Export file as... 并执行。
  • 选择目标格式，如 Html、DOCX 等。

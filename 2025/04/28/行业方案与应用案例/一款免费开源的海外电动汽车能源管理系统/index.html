一款免费开源的海外电动汽车能源管理系统

EVCC 是一个专注于电动汽车的能源管理系统。该软件控制您的 EV 充电器或智能插头。它与您的车辆、逆变器或家庭存储设备通信，以做出明智的充电决策。

EVCC 的核心功能就是利用多余的太阳能给电动汽车充电，系统收集发电量、家用电池状态、电价、电动汽车充电状态等信息。

借助这些数据，evcc 可以控制您的电动汽车充电器，以最大限度地利用光伏剩余电量。如果您有动态电价，您可以定义充电计划或设置价格限制，并在最便宜的时间充电。

EVCC的三种充电模式

- 太阳能模式是奇迹发生的地方

根据可用的剩余电量，EVCC启动和停止充电过程并调整电量。

- Min+Solar 模式是前两种模式的混合。

当模式激活时，EVCC会立即开始充电，无论是否有剩余电量，但只使用充电器所需的最小电量。如果剩余电量超过该值，EVCC将调整电量。

- 快速模式能够以尽可能高的功率充电，而无需考虑光伏过剩。

此模式基本上复制了您的壁挂式充电盒本身已经能够完成的功能。

在这三种模式下，一旦达到设定的充电限制，充电就会停止。充电计划设定了达到特定充电限制的时间，并结合了太阳能和快速模式：车辆以剩余电量充电，并在最迟可能的时间启动快速模式以达到目标充电限制。如果您有电池，太阳能模式还允许您在电池和车辆充电之间设置优先级。

EVCC的支持功能

- 简单明了的用户界面

- 支持的充电器范围广泛：

  • ABL eMH1, Alfen (Eve), Bender (CC612/613), cFos (PowerBrain), Daheimladen, Ebee (Wallbox), Ensto (Chago Wallbox), EVSEWifi/ smartWB, Garo (GLB, GLB+, LS4), go-eCharger, HardyBarth (eCB1, cPH1, cPH2), Heidelberg (Energy Control), Innogy (eBox), Juice (Charger Me), KEBA/BMW, Mennekes (Amedio, Amtron Premium/Xtra, Amtron ChargeConrol), older NRGkicks (before 2022/2023), NRGKick Gen2,openWB (includes Pro), Optec (Mobility One), PC Electric (includes Garo), Siemens, TechniSat (Technivolt), Tinkerforge Warp Charger, Ubitricity (Heinz), Vestel, Wallbe, Webasto (Live), Mobile Charger Connect and many more

    • EEBus 支持（Elli、PMCC）

    • 实验性 OCPP 支持

    • 自行构建：Phoenix Contact（包括 ESL Walli）、EVSE DIN

    • 智能家居网点：FritzDECT、Shelly、Tasmota、TP-Link

- 支持多种电网、光伏、电池和充电器电表：

  • ModBus：Eastron SDM、MPM3PM、ORNO WE、SBC ALE3 等等，完整列表见 https://github.com/volkszaehler/mbmd#supported-devices

  • 集成系统：SMA Sunny Home Manager 和电表、KOSTAL 智能电表 （KSEM， EMxx）

  • 兼容 Sunspec 的逆变器或家用电池设备：Fronius、SMA、SolarEdge、KOSTAL、STECA、E3DC 等

  • 以及其他各种：Discovergy、Tesla PowerWall、LG ESS HOME、OpenEMS （FENECON）

- 车辆集成（充电状态、远程充电、电池和预调节状态）：

  • 奥迪、宝马、雪铁龙、达契亚、菲亚特、福特、现代、捷豹、起亚、路虎、梅赛德斯-奔驰、迷你、日产、欧宝、标致、保时捷、雷诺、西雅特、Smart、斯柯达、特斯拉、大众、沃尔沃……

  • 服务： OVMS， Tronity

- 与任何充电器/仪表/车辆集成的插件：

  • Modbus, HTTP, MQTT, Javascript, WebSockets and shell scripts Modbus、HTTP、MQTT、Javascript、WebSockets 和 shell 脚本

- 使用 Telegram、PushOver 等功能发送状态通知

- 使用 InfluxDB 和 Grafana 进行日志记录

- 使用支持的充电器（例如，将 smartWB 标记为 OLC）进行低至 mA 级的精细充电功率控制

- 用于与家庭自动化系统集成的 REST 和 MQTT API

- Home Assistant 和 OpenHAB 的附加组件（不是由 evcc 核心团队维护的）

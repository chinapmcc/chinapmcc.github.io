Typora介绍

1. 软件概述

Typora 是一款由 Abner Lee 开发的轻量级 Markdown 编辑器/阅读器，以其简洁直观的界面和强大的功能受到广泛欢迎。它支持 Windows、macOS 和 Linux 等多个操作系统，提供 15 天免费试用期，正式版价格为 14.99 美元或 89 元人民币，最多可在 3 台设备上使用。

2. 核心特点

  • 所见即所得：用户在编辑 Markdown 文档时，可以直接看到最终的渲染效果，无需手动切换预览模式。
  • 简洁界面：界面设计简洁，没有多余按钮和菜单，支持多种主题和外观自定义。
  • 实时预览：输入 Markdown 语法时自动转换为对应格式化文本，支持实时预览排版效果。
  • 丰富的 Markdown 语法支持：支持标题、列表、表格、代码块、图片、数学公式（LaTeX）、流程图等多种扩展语法。
  • 多种导出格式：支持将文档导出为 PDF、HTML、Word 等多种格式。

3. 功能亮点

  • 图片拖拽插入：支持直接将图片拖拽到编辑器中，简化操作。
  • 大纲面板：帮助用户快速浏览文档结构，适合长文档写作。
  • 拼写和语法检查：帮助用户检查文档中的拼写和语法错误。
  • 自定义快捷键：用户可以根据自己的使用习惯设置快捷键。
  • 多文档关联视图：新增多文档关联视图模式，方便同时编辑多个文档并保持内容同步更新。
  • 智能排版：支持基于 AI 技术的智能排版功能，可自动优化文本格式与结构。

4. 适用场景

  • 个人写作：适合日常写作、记录笔记或撰写博客。
  • 技术文档编写：支持代码高亮和复杂格式，适合编写技术文档。
  • 学术论文写作：支持导出为 LaTeX 格式，适合学术写作。
  • 演讲稿制作：可以快速创建结构清晰的演讲稿。
    Typora 以其简洁的界面和强大的功能，成为 Markdown 编辑的首选工具之一，适用于多种写作和文档编辑场景。

3.1 关闭软件激活弹窗

上述激活弹窗每次打开软件都会提示，在文件开头部分加入以下代码后可自动将其关闭。
打开文件：Typora\resources\page-dist\static\js\0.99879679.chunk.js
功能作用是在弹窗出现后自动点击关闭按钮，256为毫秒时间，根据自己电脑启动时长设置；
如报错”A JavaScript error occurred in the main process”，说明时间太短，要加长时间。

3.2 解决Typora闪退

打开注册表：Win+R，输入regedit，回车。
找到注册表：计算机\HKEY_CURRENT_USER\Software\Typora
右键Typora，选择Administrators，勾选拒绝，点击应用。

3.3 解决只有现弹窗不出现主窗口

在终端cmd运行以下命令，做重置设置，用于删除 Typora 的用户配置文件和注册表项。

  • profile.data 文件通常包含 Typora 的用户配置信息，如窗口位置、最近打开的文件等。删除这个文件可以重置 Typora 的用户配置，使其恢复到默认状态。
  • Typora 在安装和运行过程中会在 Windows 注册表中存储一些配置信息。删除这些注册表项可以清除 Typora 的相关设置，使其在下次启动时重新初始化这些设置。

4、方法2：修改时间，无限期使用Typora

打开注册表：Win+R，输入regedit，回车。
找到注册表：计算机\HKEY_CURRENT_USER\Software\Typora
Typora 通过检查注册表中的 IDate 值，为安装日期，然后来计算试用时长。
每次通过修改这个值，来达到无限期的使用 Typora。

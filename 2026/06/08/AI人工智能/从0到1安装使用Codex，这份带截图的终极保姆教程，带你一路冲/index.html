Codex 简介

OpenAI Codex 是一个 AI 编程代理（AI Coding Agent），目标不是帮你补全代码，而是直接参与并完成整个开发任务—写代码、修 Bug、跑测试、提 Pull Request。

传统聊天机器人只有一个输入框，而 Codex App 不一样，它本质上是一个运行在本地电脑上的 AI Agent 工作台。

它不仅能回答问题，还能：

  • 读取本地文件
  • 操作桌面应用,如Excel等
  • 浏览网页
  • 运行命令
  • 调用外部工具
  • 自动执行任务
  • 操作浏览器

一句话定义：

Codex App 是一个具备 AI Agent 能力的本地工作平台。

传统 ChatGPT 的核心是： Codex App 的核心是：
你提问
AI 回答		 你提出目标
AI 帮你完成任务

Codex周活已破500万，Codex 近期升级三大核心，让人人都能用成为可能。

  • Agent plugins：全新插件可根据个人角色和常用工具，对Codex深度定制；

  • Annotations：在Codex输出结果上直接添加批注，即时优化代码输出；

  • Sites：仅需一个 URL，即可创建交互式网站与应用，与团队无缝共享。

下载安装CodeX

  1. 通过Microsoft Store 中搜索”Codex安装”
  2. 或通过OpenAI的Codex官网下载安装：https://chatgpt.com/zh-Hans-CN/download/
  3. 或通过Chianpmcc的公众号后台发送Codex获取安装包

安装完成后，打开Codex，显示登录窗口

  1. 使用ChatGPT账户登录（已经有免费账户或会员账户都可以）
  2. 使用其他方式登录（API Key）

    这里我们选择使用免费账户进行登录，输入邮箱和密码，点击继续

    验证授权，点击继续

    根据自己的方式自定义Codex，跳过也行。

Codex 界面说明

新对话

你可以随时在一个新对话中输入，建议一个对话做一件事情，记录的越长问的越杂乱污染就严重。

对话越来越多时，可以进行<重命名>，方便记忆使用。

搜索

对历史使用过的会话进行搜索，输入关键字即可。

插件

插件相当于Codex的左膀右臂，要会更多技能就需要安装相应的插件
安装插件后让它在白板中会业务流程图，用浏览器网站找资料，对邮件进行处理就都可以了
办公：Email、Sheets、Chrome、Data Analytics
编程：HuggingFace、Build iOS Apps、Build Web Apps
设计：Canva、Figma

自动化

针对需要按计划运行的方式，如每日简报、每周回顾、项目监控等可以创建自动化

Codex移动版

用手机连接桌面端进行协作，手机下发指令后，可在桌面端启动任务。

项目

  1. 绑定工作区
    选择一个本地文件夹作为项目目录，Codex 会以该文件夹为工作区，所有生成的文件、修改的代码都会自动保存到这个文件夹中。例如，你可以创建一个专门用于网页开发的文件夹，让 Codex 在此文件夹内生成 HTML、CSS、JavaScript 文件，方便后续管理和部署。

  2. 理解项目结构
    当绑定项目后，Codex 会自动扫描文件夹内的文件结构，了解项目的文件组成、依赖关系和核心模块。例如，对于一个前端项目，Codex 可以识别出入口文件（如 index.html）、样式文件、脚本文件等，为后续的代码生成、修改和调试提供上下文支持。

  3. 隔离任务上下文
    每个项目对应一个独立的工作区，不同项目的任务上下文相互隔离。这意味着你可以在一个项目中处理网页开发，同时在另一个项目中处理数据分析，避免任务之间的干扰和混淆。例如，你可以在一个项目中让 Codex 生成网页界面，同时在另一个项目中让它分析数据并生成报告，两者互不影响。

  4. 支持多项目切换
    你可以在左边栏的“项目”列表中快速切换不同的项目，方便同时处理多个任务。例如，你正在开发一个网站，同时需要维护一个移动应用，可以通过切换项目快速在两者之间切换工作，无需重新绑定文件夹或重新输入任务描述。

新建项目或选择已有项目 项目最好专项专用，不要一个项目问东问西，比如创建“充电app”

主对话区

“+”添加附件 或 使用某项插件

权限

权限分为三挡，如果没有特别重要的资料，就直接放开干吧，不然你得多次确认。
默认权限（需用户确认操作）
自动审查（自动判断操作安全性）
完全访问权限（直接读写文件，运行命令，风险较高）。

模型与推理等级

根据你的任务难度来选择低、中、高、超高

语音

懒得打字就直接点击语音说话就行。

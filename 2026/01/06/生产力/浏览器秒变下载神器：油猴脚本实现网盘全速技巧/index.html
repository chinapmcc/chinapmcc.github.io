篡改猴 (Tampermonkey)

篡改猴 (Tampermonkey) 是拥有 超过 1000 万用户 的最流行的浏览器扩展之一。 它适用于 Chrome、Microsoft Edge、Safari、Opera Next 和 Firefox。

有些人也会把篡改猴(Tampermonkey)称作油猴(Greasemonkey)，尽管后者只是一款仅适用于 Firefox 浏览器的浏览器扩展程序。

它允许用户自定义并增强您最喜爱的网页的功能。用户脚本是小型 JavaScript 程序，可用于向网页添加新功能或修改现有功能。使用 篡改猴，您可以轻松在任何网站上创建、管理和运行这些用户脚本。

例如，使用 篡改猴，您可以向网页添加一个新按钮，可以快速在社交媒体上分享链接，或自动填写带有个人信息的表格。在数字化时代，这特别有用，因为网页常常被用作访问广泛的服务和应用程序的用户界面。

此外，篡改猴 使您轻松找到并安装其他用户创建的用户脚本。这意味着您可以快速轻松地访问为您喜爱的网页定制的广泛库，而无需花费数小时编写自己的代码。
https://www.tampermonkey.net/

篡改猴脚本库

有了篡改猴，先到脚本库中查找功能脚本，然后安装脚本即可。

典型脚本示例

  • 广告屏蔽与移除（横幅、弹窗、视频广告等）
  • 视频播放增强（倍速调整、VIP视频解锁、网课自动播放功能）
  • 网页限制解除（解除文库的复制限制、右键解锁、下载等限制）

Greasy Fork

https://greasyfork.org/
Greasy Fork 是 2014 年由 Jason Barnabe 创建的“用户脚本（UserScript）托管与分发平台”，也是目前全球最大、最活跃的中文友好脚本库，定位相当于“浏览器的 App Store”——只是这里所有的“App”都是一段段轻量的 JavaScript 代码，通过 Tampermonkey、Violentmonkey 等扩展注入页面，实时改变网页外观或功能行为。

OpenUserJS

https://openuserjs.org/
OpenUserJS 是一个用户脚本托管平台，类似于 Greasy Fork，允许用户发布、共享和安装 JavaScript 用户脚本，通过浏览器扩展（如 Tampermonkey、Violentmonkey）来增强网页功能。

示例：网盘下载加速方案

加速下载文件逻辑：拿到网盘文件的直接链接，然后通过下载工具来加速下载。

工作流程示例

sequenceDiagram
    participant U as 用户
    participant B as 浏览器
    participant TM as Tampermonkey
    participant S as Greasy脚本
    participant BP as 网盘
    participant DL as 下载器(Motrix)

    U->>B: 访问网盘分享链接
    B->>TM: 页面加载完成
    TM->>S: 自动执行网盘脚本
    S->>BP: 模拟VIP用户请求
    BP-->>S: 返回文件直连链接
    S->>B: 注入"直接下载"按钮
    U->>B: 点击下载按钮
    B->>DL: 调用Motrix API
    DL->>BP: 多线程请求文件
    BP-->>DL: 分片传输数据
    DL-->>U: 完成高速下载

LinkSwift

https://github.com/hmjz100/LinkSwift
一个基于 JavaScript 的网盘文件下载地址获取工具。基于【网盘直链下载助手】修改 ，支持 百度网盘 / 阿里云盘 / 中国移动云盘 / 天翼云盘 / 迅雷云盘 / 夸克网盘 / UC网盘 / 123云盘 八大网盘

  • 手动下载安装：LinkSwift网盘直链下载助手.user.js
  1. 安装成功后，刷新页面会出现一个下载助手按钮。
  2. 选择下载的文件，然后按下载工具获取链接
  3. 点击推送链接到下载器，开始下载文件

Motrix

https://motrix.app/zh-CN/
一款全能的下载工具，支持下载 HTTP、FTP、BT、磁力链接等资源。

  • 下载安装 Motrix：https://motrix.app/zh-CN/download
  1. 软件打开的状态下，就开始自动下载了。
    测试下载过程时快时慢，最慢大概100Kb/s，快的时候有2~3MB/s，速度通常与热门资源、稳定带宽有关系，但至少比网页下载快和方便。

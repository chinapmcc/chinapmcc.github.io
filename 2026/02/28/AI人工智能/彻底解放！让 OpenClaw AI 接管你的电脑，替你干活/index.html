OpenClaw 是什么？

🦞OpenClaw 是一个开源的、能真正替你“动手干活”的个人AI助手。你可以把它理解成一个7x24小时在线的“数字员工”或“AI管家”
• 最初叫 Clawdbot → 因 Anthropic 商标要求改为 Moltbot → 最终定名 OpenClaw
• 一个能部署在你个人电脑（Mac、Windows、Linux）上的开源AI代理框架。你可以通过 WhatsApp、iMessage、Telegram等聊天软件向它下达指令。

OpenClaw 怎么这么火？

之前的 AI 工具，不管多强大，本质上都是一个网页里的输入问题，它回答。它不能主动做事，不能连接你的工具，不能记住你是谁。
但OpenClaw 不一样，它把 AI 从”对话框”里解放了出来，它是一个完整的 AI Agent 运行平台：

功能特性 说明
1. 多渠道通信 通过 Telegram、WhatsApp、Discord、短信等多种聊天工具与用户交互，支持用户习惯使用的任何平台
2. 工具调用 能执行命令行操作、读写本地文件、上网搜索信息、操作浏览器、调用各类API接口
3. 技能系统（Skills） 像手机安装App一样，可为助手动态安装新技能：整理文件、预订行程、管理日程、比价购物等
4. 记忆系统 三层记忆架构：短期记忆（当天对话上下文）、长期记忆（MEMORY.md文件存储）、身份记忆（SOUL.md个性化设定）
5. 心跳机制 主动式服务：无需用户触发，助手会定期自动”醒来”检查待办事项、提醒和需要处理的任务
6. 完全本地部署 所有数据运行在用户本地机器上，不经过任何第三方服务器，确保隐私和数据主权

OpenClaw的爆火不仅仅是又一个新工具的诞生，它代表了一种技术范式的转变：

  • 从“对话”到“执行”：它让AI从只能聊天的“大脑”，变成了能动手干活的“四肢”，实现了真正的人机交互逻辑重构。

  • 对App形态的冲击：OpenClaw的创始人曾预言，未来80%的App可能会消失，因为AI代理能直接调用数据和API完成任务，而不再需要一个独立的用户界面。

  • 搅动产业生态：它的出现已经迅速带动了上下游产业链，比如阿里云、腾讯云等纷纷推出一键部署服务，甚至让Mac mini等适合部署它的硬件都卖断了货。

教程

下面跟着这篇保姆式实操教程，在你电脑上本地部署一个OpenClaw，也洋气一回，效率翻倍。🤭

本地部署操作步骤

① 前置条件

  • 需要安装Node.js ≧ v22.x.x
  • 需要安装Git
  • 需要安装Windows WSL2
  • 需要AI模型API Key

② 安装OpenClaw

  1. Windows 中用管理员打开Windows PowerShell，输入以下安装指令
  2. 阅读并确认安全警告 选择Yes
  3. 使用⇅上下方向键（回车），选择配置模式：
    • QuickStart（快速开始）- 推荐选项，快速完成配置
    • Manual（手动配置）- 逐步手动配置所有选项，后续可通过 openclaw configure 命令调整配置
  4. 选择模型（选Skip for now（稍后配置百炼模型））
    • 模型名称，qwen3-max-2026-01-23、qwen3-coder-plus
    • API Key属地URL 华北2（北京）：https://dashscope.aliyuncs.com/compatible-mode/v1
    • API Key：sk-96xxxxxxxxxxxxxxxfadde
  5. 按提供者筛选模型，选择All providers
  6. 默认模型，选择Keep current
  7. 配置渠道，选择Skip for now
  8. 配置技能，选择No
  9. 是否启用钩子，⇅上下键选择session-memory，用空格键选中，回车
  10. 打开链接
  11. 浏览器会自动打开 OpenClaw 的控制台页面（http://127.0.0.1:18789）
    打不开页面可能是网关没有开启成功，可尝试下面两种方法
    • 用管理员启动PowerShell，安装引导：openclaw onboard
    • 另开一个PowerShell，启动 Gateway 网关：openclaw gateway

③ Web控制台配置

  1. 在终端中运行以下命令启动页面：openclaw dashboard
    左侧菜单栏中依次选择：Config > Authentication，点击菜单下方的Raw。
  2. 添加百炼API配置
    复制以下配置信息，替换原"agents": {...},部分，并将 DASHSCOPE_API_KEY 替换为你的百炼 API Key。
    主要现在有免费KEY可以过渡下，当然你也可以使用时他的AI API KEY，推荐使用Claude。
    模型还支持 OpenAI GPT-5.2、Google Gemini 3 Pro、Moonshot（Kimi K2.5）、MiniMax M2.1、Z.AI（GLM-4.7）、xAI（Grok）、Qwen、Venice、OpenRouter 等 10+ 家模型。

配置完成后，单击右上角 Save 保存配置，单击 Update。

④ 开始对话

  • Web 界面中对话
    使用命令：openclaw dashboard，即可通过 Web 界面的方式开始对话。
    使用示例：帮我整理”C:\Users\Desktop\Temp”所有照片，按日期进行目录分类；
    示例结果：不一会儿所有照片会自动按日期目录整理好；

  • 命令行中对话
    使用命令：openclaw tui，即可通过命令行的方式开始对话

快速完成初始配置向导

首次安装后，OpenClaw 会自动启动配置向导，帮助您快速完成初始设置。
您也可以手动执行openclaw onboard命令进行配置。
配置项 建议配置
I understand this is powerful and inherently risky. Continue? 选择 Yes
Onboarding mode 选择 QuickStart
Model/auth provider 选择 Skip for now（配置模型）
Filter models by provider 选择 All providers
Default model 选择 Keep current
Select channel (QuickStart) 选择 Skip for now（配置渠道）
Configure skills now? (recommended) 选择 No
Enable hooks? 按空格键选中选项，按回车键进入下一步
How do you want to hatch your bot? 选择 Do this later
选项 功能 是否推荐
Skip for now 跳过，不启用任何 hook ✅ 新手建议先跳过
boot-md 自动在启动时生成 Markdown 文件（如日志或文档） ⚠️ 可选，适合需要记录过程的人
command-logger 记录所有执行过的命令到日志文件 ✅ 推荐，便于调试和复盘
session-memory 保存当前会话的上下文（如聊天历史、变量），下次打开可恢复 ✅ 强烈推荐，提升体验

常用命令

命令 作用 备注 / 参数
npm install -g openclaw@latest --registry https://registry.npmmirror.com 安装 openclaw
openclaw onboard 安装引导
openclaw status 查看 Gateway 状态 检查网关是否可达及运行状况
openclaw health 健康检查 主要检测 core 运行和依赖情况
openclaw doctor 综合诊断与修复建议 可配合 --yes / --non-interactive 自动执行
openclaw configure 交互式配置向导 用于设置模型、通道、凭据等
openclaw config get <path> 获取配置值 指定路径提取配置
openclaw config set <path> <value> 设置配置项 支持 JSON5/raw 文本
openclaw config unset <path> 清除配置项 移除单个键值
openclaw channels list 列出已登录通道 可观察 WhatsApp/Telegram 等登录状态
openclaw channels login 登录新的通道账号 用于扫描/授权链接
openclaw skills list 列出技能 查看可用/已安装的技能
openclaw skills info <skill> 技能详情 观察某项技能参数或版本
openclaw plugins list 列出插件 查看已安装插件
openclaw plugins install <id> 安装插件 例如 @openclaw/voice-call
openclaw plugins enable <id> 启用插件 之后通常需要重启网关
openclaw logs --follow 显示日志 --json / --plain / --limit

 等组合使用
openclaw gateway 启动 Gateway 网关
openclaw gateway install 安装系统服务 根据平台注册 Gateway 守护进程
openclaw gateway start 启动 Gateway 网关 系统服务模式下启动
openclaw gateway stop 停止 Gateway 网关 同上
openclaw gateway restart 重启 Gateway 网关 适合配置变更后应用
openclaw gateway status 网关系统服务状态 不同于 openclaw status，会探测服务单元
openclaw uninstall 卸载 Gateway 服务及数据 官方推荐使用
openclaw uninstall --all --yes --non-interactive 全自动卸载 包含状态、workspace、插件等
openclaw uninstall --state 删除状态文件 不删除 workspace/CLI
openclaw uninstall --workspace 删除工作区 移除 agent/workspace 文件
openclaw uninstall --service 仅卸载服务 不删除数据
openclaw uninstall --dry-run 模拟卸载 显示结果但不实际执行

常见问题

  • Q：安装脚本报错？
    • A：Node.js 版本太低：OpenClaw 需要 Node.js 22+。
    • 检查版本：node -v
    • 手动升级：
      curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash
      nvm install 22
  • Q：想重新配置？
    • A：随时可以重新运行向导：openclaw onboard
    • A：或者只改部分：openclaw configure
  • Q：是否有官方文档？
    • A：有，支持中，英，日的官方文档：https://docs.openclaw.ai/zh-CN
  • Q：有哪些Skills可用？
    • A：skill library.：https://clawhub.ai/skills

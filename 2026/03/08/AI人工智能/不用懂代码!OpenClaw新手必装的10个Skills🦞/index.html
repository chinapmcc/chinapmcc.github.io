Skills 是什么？

OpenClaw 是一个开源的 AI 代理框架，而 Skills 就是它的“插件”或“技能包”
下面这个比喻可以帮你快速理解它们的关系：

  • OpenClaw 本体：就像电脑的操作系统，负责理解你的指令、调度资源，但本身不执行具体任务。

  • OpenClaw Skills：就像安装在系统上的各种 APP（应用程序），比如“PRD生成器”、“指标解读器”。安装后，OpenClaw 就学会了做这些具体的事情。

所以，要让 AI 获得执行特定任务的能力，比如操作浏览器、管理文件或分析数据等，你首先需要安装一个对应 Skill（技能插件） 。

Skill 常见问题

1.安装Skill 报错Rate limit exceeded

错误提示 “Rate limit exceeded”（速率限制超限）表示 ClawHub 的 API 请求频率超过了限制。

方法1.ClawHub 的速率限制通常是 临时性 的，等待一段时间自动恢复。
方法2.如果使用的是公司/校园网，尝试切换手机等其他网络
方法3.使用本地缓存安装

2.Clawhub通常有哪些命令

1.搜索Skill

后续想要什么技能，直接用自然语言搜就行。

2.安装Skill

比如安装Gmail：clawhub install gmail，装完记得重启会话才能生效。

3.检查Skill

技能状态检查，在列表中可以查看已安装Skill。

4.卸载Skill

通过命令卸载Skill，比如安装Gmail；也可以手动删除Skill 下的目录即可。

5.批量更新

一键把所有已装Skill更新到最新版。

3.OpenClaw Skill技能存储在哪里？

Skill技能可以从捆绑默认文件、本地的 ~/.openclaw/skills 文件夹，以及当前工作区的 /skills 目录加载。工作空间技能覆盖本地权限，本地覆盖捆绑。

安装到用户目录（全局）

适用场景：

  • ✅ 正式安装 Skill，长期使用
  • ✅ 跨项目共享的通用 Skill
安装到当前目录（本地）

适用场景：

  • ✅ 临时测试 Skill，不想污染全局配置
  • ✅ 项目特定 Skill（如某项目专用的自定义 Skill）
  • ✅ 多版本 Skill 并存测试

4.如何自动诊断？

openclaw doctor 会一次性检查 Node.js 版本、配置文件有效性、频道连接、API 密钥状态等。

5.技能从三个位置加载（按优先级排序）：

  1. 工作区技能（<workspace>/skills/） — 最高优先级
  2. 托管技能（~/.openclaw/skills/） — 所有代理共享
  3. 内置技能 — OpenClaw 包中自带的默认技能

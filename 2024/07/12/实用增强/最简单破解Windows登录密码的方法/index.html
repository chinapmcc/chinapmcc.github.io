最简单破解Windows登录密码的方法

破解密码有好多种方法，通常可以重置电脑，忘记密码等方式找回。
今天介绍一种通过Windows PE中的工具来进行重置密码，且不会删除电脑原有文件。

什么是Windows PE？

Windows PE（Windows Preinstallation Environment）是微软开发的一种特殊的、最小化的Windows操作系统环境。它基于Windows内核，但仅包含了运行必要的最低限度的服务和驱动程序。Windows PE的主要用途是在没有完整安装Windows操作系统的情况下，为计算机提供一个临时的操作环境。

Windows PE的一些关键特点和用途：

1. 预安装环境

Windows PE主要用于安装、部署和修复Windows操作系统。它可以在计算机启动前运行，提供必要的工具和服务来执行系统安装、故障排除、数据恢复等任务。

2. 最小Win32子系统

它基于保护模式下的Win32子系统，但去除了不必要的组件，只保留了运行基本命令行工具、加载驱动程序、访问存储设备等功能所需的部分。

3. 可定制性

Windows PE可以被定制以适应不同的硬件配置和需求。它可以添加额外的驱动程序和工具，以便支持各种硬件设备和执行特定的任务。

4. 网络连接

Windows PE支持网络连接，允许用户访问网络资源，进行远程故障排除和软件分发。

5. 硬件验证

它可以用来测试硬件兼容性和进行基本的硬件验证过程。

6. 不作为日常操作系统

Windows PE并非设计为一个完整的、可供日常使用的操作系统，它的目的是作为安装、部署、诊断和修复过程的一部分。

Windows PE被广泛应用于IT管理和系统维护领域，例如在创建系统恢复盘、系统镜像部署、系统故障修复和数据恢复场景中。它通常被包含在可启动的USB闪存驱动器、光盘或网络引导环境中。

工具准备

U盘启动工具

  • 下载地址(示例)：https://github.com/pbatard/rufus/releases/download/v4.5/rufus-4.5.exe

Windows PE

  • 下载地址(示例)：https://www.hirensbootcd.org/files/HBCD_PE_x64.iso

  • 微软官方手册：https://learn.microsoft.com/zh-cn/windows-hardware/manufacture/desktop/download-winpe--windows-pe?view=windows-11

  • 其他的WinPE：https://firpe.cn/

破解密码操作过程

  1. 插上U盘（会格式化U盘，不要存放重要资料）

  2. 运行启动工具(rufus-4.5.exe)，点击选择已下载的HBCD_PE_x64.iso，点击开始

  3. 将制作好的启动U盘插入到要恢复密码的电脑上

  4. 电脑开机时，连续按F8键，会自动调出启动引导菜单，选择U盘来引导启动，保存设置，然后重启。
    通常路径：Boot → Hard Disk Boot Priority/Device Priority → USB-HDD0：SanDisk 不同品牌、不同型号的电脑进入 BIOS 的快捷键和路径有所差异，
    常用键：Esc、Delete、F1、F2、F10、F11 或 F12。

  5. 点击 NTPWEdit 来修改密码
      NTPWEdit 是基于 Windows NT 系统（如 Windows 2000，XP，Vista，7,8,10）开发的密码编辑器，它可以更改或删除本地系统帐户的密码。也就是NTPWEdit 通过直接修改位于 C:\WINDOWS\SYSTEM32\CONFIG\SAM 文件来更改密码。
      

  6. 选择忘记密码的账户，点击更改密码(Change Password)，输入新密码或者为空，保存重启即可进入系统

Amazon Elastic Compute Cloud（Amazon EC2）提供最广泛、最深入的计算平台，拥有超过 500 个实例，可选择最新的处理器、存储、网络、操作系统和购买模型，以帮助您最好地满足工作负载的需求。我们是首家支持英特尔、AMD 和 Arm 处理器的主要云提供商，既是唯一具有按需 EC2 Mac 实例的云，也是唯一具有 400 Gbps 以太网网络的云。我们为机器学习培训提供最佳性价比，同时也为云中的每个推理实例提供了最低的成本。与任何其他云相比，有更多的 SAP、高性能计算 (HPC)、机器学习 (ML) 和 Windows 工作负载在 AWS 上运行。

免费服务器就是香，不用白不用，你可以用来搭建网站、代理IP、VPN等，废话不多说直接按步骤去申请吧。

  • 中国区域账户

    • 如果您还没有账户，请先注册账户。
    • 需要提供企业注册证照和网络安全负责人的有效身份证件进行账户注册

  • 海外区域账户

    • 无需营业执照和身份证认证
    • 需要使用到信用卡认证
    • 以下注册过程也是以海外区域为例

一、注册AWS

AWS 海外区域免费体验 AWS 中国区域免费体验
https://portal.aws.amazon.com/billing/signup https://www.amazonaws.cn/campaign/CloudService/

  1. 邮件地址及账户名

  2. 联系人信息

  3. 账单信用卡信息（如果只是薅羊毛，记得关掉续费，免得第二年自动续费）

  4. 确认信息

  5. 选择<基本支出-免费>

  6. 注册成功

  7. 收到邮件通知，说明已经构建完成。

二、登录AWS

  1. 登录
  2. 先选择要部署的服务器节点区域，点击EC2，创建实例，安装WordPress

收集了一整套的设计资源类免费网站，为创意工作提供了宝贵的资源，无论是需要美观的图片、令人印象深刻的插图还是直观的图标，都能轻松找到；

无论您是一名开发者、设计师、产品经理、市场运营还是写PPT，任何需要视觉素材的从业者可以在这些资源网站上为您提供了广泛的选择，以满足各种不同的需求，帮助您打造令人印象深刻的作品。

✨ 产品设计素材套装✨

A. 图标库

A.1 IconPark

  • 简介：
    • IconPark图标库是一个通过技术驱动矢量图标样式的开源图标库，致力于构建高质量、统一化、可定义的图标资源，让大多数人都能够选择适合自己的风格图标。
  • 亮点：
    • 可以实现根据单一SVG源文件变换出多种主题，具备丰富的分类、更轻量的代码和更灵活的使用场景
  • 关键词：
    • 自定义颜色、图标大小、SVG、PNG
  • 官网：
    • https://iconpark.oceanengine.com/official

A.2 iconfont

  • 简介：
    • 阿里巴巴官方推出的「矢量图标管理与交流平台」，设计师上传原创图标，用户可按需下载 SVG/PNG/AI 等多格式文件，或直接生成 Web-Font，供前端一行代码调用 。
  • 亮点：
    • 1200w+ 图标，中文/英文/拼音语义搜索即出结果
    • 在线批量改色、改粗细、转多色字体，实时预览
    • “购物车+项目”机制，一键打包下载或生成 CDN 链接，支持团队协作
    • 三种调用方式（Unicode / Font-class / Symbol），兼容 IE9+ 与全部现代浏览器
  • 关键字：
    • 矢量图标、图标字体、在线改色、项目协同
  • 官网：
    • https://www.iconfont.cn/

A.3 Unicorn icons

  • 简介：
    • 一套由 Khushmeen 创作的「动画图标库」，提供 Lottie 动效与静态 SVG，可一键嵌入 Web / App / PPT。
  • 亮点：
    • 纯动画：所有图标自带 60fps Lottie 动效，文件小、可循环
    • 即拿即用：CDN 一行代码即可调用，支持 React 与 Vue 组件
    • 风格统一：线性彩色风，适合 SaaS / 营销类界面
  • 关键字：
    • 动效图标、彩色线性、笔画宽度、背景、比例、SVG、JSON
  • 官网：
    • https://unicornicons.com/icons

A.4 Lordicon

  • 简介：
    • 专注于「交互式 Lottie 图标」的订阅制平台，目前收录 8,000+ 个微交互动画，支持点击、悬停、循环三种触发方式。
  • 亮点：
    • 触发多样：悬停、点击、循环、Morph、Burst 五种交互模式
    • 多平台 SDK：提供 Web、iOS、Android、Flutter 即用组件
    • 在线编辑器：可实时调色调速，再导出 JSON / GIF / SVG
  • 关键字：
    • 交互图标、可自定义颜色、悬停触发、SVG、GIF、WebP、JSON、MP4、AEP、HTML
  • 官网：
    • https://lordicon.com/icons

B. 插画库

B.1 illustration kit

  • 简介：
    • 一个完全免费的「手绘插画库」，提供 150+ 矢量人物与场景插画，可一键下载 SVG/PNG，并配套 Figma/Sketch 源文件。
  • 亮点：
    • 100 % 免费 & 可商用，无需署名
    • 统一手绘风格，适合空状态、引导页、营销落地页
    • 在线实时换色，下载前即可预览不同主题配色
  • 关键字：
    • 手绘风格、自定义颜色、可缩放、矢量插图、SVG、PNG
  • 官网：
    • https://illustrationkit.com/illustrations

B.2 unDraw

  • 简介：
    • 由 Katerina Limpitsouni 于 2017 年创建的开源扁平插画库，目前收录 800+ 幅现代矢量场景插画，全部免费且可商用，无需署名
  • 亮点：
    • 在线一键换色：6 组预设主题或自定义色值，实时预览全局配色
    • 双格式下载：SVG（可二次编辑、无损缩放）+ PNG（像素级场景）
    • 免注册、持续更新：直接搜索关键词即可下载，谷歌 / 微软 / Facebook 等也在用
  • 关键字：
    • 开源插画、自定义颜色、扁平风格、在线换色、SVG、PNG
  • 官网：
    • https://undraw.co/illustrations

C. 样机 / UI 套件

C.1 placeit

  • 简介：
    • 由 Envato 集团运营的在线设计平台，无需安装软件即可在浏览器内创建品牌 Logo、产品样机、社媒海报及宣传视频，目标用户为“不会设计的创作者”
  • 亮点：
    • 全球最大：16 万+ 模板，涵盖 5 万+ 实拍样机，品类从 T 恤到手机壳到 YouTube 片头
    • 零门槛：拖放式在线编辑器，上传设计 3 秒自动贴图、实时预览
    • 全格式输出：PNG、JPG、MP4、GIF，高分辨率，付费即可商用
    • 订阅灵活：月度 7.47 美元起，无限下载，随时可取消
  • 关键字：
    • 在线样机、零代码设计、无限模板
  • 官网：
    • https://placeit.net/free-templates

C.2 Craftwork

  • 简介：
    • Craftwork.design 是由全球顶尖艺术家共建的高品质「设计资产商店」，提供 UI Kits、插图、Mockup、字体、图标等付费与免费资源，每月持续上新。
  • 亮点：
    • 顶级手作：所有素材均为艺术家原创，风格统一、细节精致，可直接用于商业项目
    • 免费专区：长期更新 Freebies，注册即可下载完整源文件（Figma/Sketch/PSD）
    • 会员折扣：订阅后全场 7 折起，并享新资源首发 48 小时抢先下载权
    • 一站式：从移动端 UI 到品牌样机，一套账号全部搞定，减少多站切换成本
  • 关键字：
    • 高端设计资产、原创插画、UI Kit
  • 官网：
    • https://craftwork.design/

D. 多媒体素材

D.1 Mixkit

  • 简介：
    • 由 Envato 团队运营的「全免费多媒体素材库」，提供 4 万+ 无水印高清视频、音乐、音效、PR/AE/FCP 模板与插画，全部可商用，无需注册即可下载 。
  • 亮点：
    • 免版权：遵循 Mixkit License，可自由下载、修改、分发，商业项目无需署名
    • 高规格：4K 分辨率、10+ 大类细分子标签，可快速筛选竖屏/横屏/分辨率
    • 一站式：视频 + 音乐 + 音效 + 视频模板 + 插画，一站在手，剪辑不愁
    • 零门槛：无需账号、不限次数、下载即用
  • 关键字：
    • 产品宣传片、免费商用、4K 视频、无水印、AE/PR 模板
  • 官网：
    • https://mixkit.co/free-stock-art/

E. 高清图库

E.1 Hippopx

  • 简介：
    • Hippopx 是一个免版权图库，收录 20 万+ 高清摄影图片，全部基于 CC0（Creative Commons Zero）协议，个人与商业用途均可免费下载、修改，无需署名
  • 亮点：
    • 高分辨率原图：可直出印刷级品质，也支持按手机/平板等常用尺寸一键裁剪下载
    • 中文友好：界面与搜索均支持中文关键词，标签分类细致，找图精准
    • 零门槛：无需注册、无广告、无限量下载，真正做到“即搜即得”
    • 跨设备：PC、移动端自适应，随时随地可访问
  • 关键字：
    • 高清图库、中文搜索、无注册下载、CC0 免版权
  • 官网：
    • https://www.hippopx.com/zh

E.2 Unsplash

  • 简介：
    • 2013 年创立于加拿大，现隶属 Getty Images 的全球顶级免费图库，拥有 500 万+ 高清摄影图片，全部可个人及商业用途免费使用
  • 亮点：
    • CC0 免费商用：无需注册、无需署名，可自由编辑、再发布
    • 超高质量：支持 4K/8K 分辨率，所有照片均经人工审核
    • 搜索精准：关键词、颜色、主题、方向多维度筛选，支持中文
    • API 开放：开发者可一行代码调用整库图片，集成到 APP / 网站
  • 关键字：
    • 高清图库、API 接入、免署名、CC0 免版权、全球最大免费图库
  • 官网：
    • https://unsplash.com/

F. 灵感 / 通用设计平台

F.1 Microsoft Designer

  • 简介：
    • 微软 2022 年 10 月推出的云端 AI 设计工具，基于 DALL-E 2 等生成式 AI 模型，可将一句话直接转化为海报、社交媒体图、邀请函、Logo 等成品，也可调用海量模板进行二次编辑
  • 亮点：
    • AI 文生图：输入一句描述即可生成多种风格图像，再自动排版成完整设计
    • 零门槛：拖拽式界面、中文提示可识别，新手 30 秒出图
    • Microsoft 365 全家桶集成：Word、PowerPoint、Teams 一键插入，实时协作
    • 免费基础版：注册微软账号即可无限次使用，付费订阅解锁高级模板
  • 关键字：
    • AI设计、文生图海报、DALL-E 2、Microsoft 365、零门槛
  • 官网：
    • https://designer.microsoft.com/

一句话速记

要整套模板先去 Craftwork，缺图标找 Iconfont，想加动效用 Lordicon，空状态插画 unDraw，配图 Hippopx + Unsplash，视频音乐 Mixkit，AI 生成兜底 Microsoft Designer。
